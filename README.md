# Triboma Stepwise Teacher

## 📋 Deskripsi Solusi
**Triboma Stepwise Teacher** adalah aplikasi web berbasis Python (Flask) dan kecerdasan buatan (AI) yang dirancang untuk membantu permasalahan nyata para guru (*teacher burnout*) dalam mengoreksi tugas lembar jawaban siswa secara manual. 

Dengan fitur *step-by-step grading* berbasis AI *Computer Vision/Scan*, guru tidak perlu membawa setumpuk kertas ke mana-mana. Sistem akan otomatis mencocokkan langkah pengerjaan siswa dengan acuan dari guru dan memberikan penilaian objektif beserta penjelasan (*feedback*).

## 🎯 Kategori / Subtema
* **Kategori:** Web
* **Subtema:** Smart & Fun Education[cite: 5, 11]

## 🛠️ Teknologi yang Digunakan
* **Backend:** Python, Flask
* **AI Integration:** OpenAI API (GPT-4o / Vision)
* **Environment Management:** python-dotenv
